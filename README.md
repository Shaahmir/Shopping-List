# Shopping List

A simple shopping list Android app built with **Kotlin** and **Jetpack Compose**.

This is a small learning project created while practicing Kotlin, Android Studio, and Jetpack Compose.

## About the App

Shopping List is a small and simple app for keeping track of the things you need to buy.

You can:

* Add new items to your list
* Edit existing items
* Delete items you no longer need

The goal of this project was to learn and practice Android app development, especially working with state and lists in Jetpack Compose, rather than build a large or complex application.

## Features

* Simple single-screen interface
* Add new shopping list items
* Edit items
* Delete items
* Instant list updates
* Light mode with custom colors
* Dark mode with custom colors
* Built using Jetpack Compose

## Built With

* **Kotlin**
* **Jetpack Compose**
* **Android Studio**
* **Gradle**

## App Structure

The app intentionally keeps the interface simple:

* One heading
* One input field for adding items
* One list showing all shopping items
* Edit and delete actions for each item

There are no multiple tabs, pages, or complicated navigation flows.

## Running the Project

Clone the repository:

```bash
git clone https://github.com/Shaahmir/Shopping-List.git
cd Shopping-List
```

Then open the project in **Android Studio** and allow Gradle to sync.

You can also build the project from the command line.

### Windows

```powershell
.\gradlew.bat assembleDebug
```

### macOS / Linux

```bash
./gradlew assembleDebug
```
